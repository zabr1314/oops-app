# Oops · 日常陪伴 App

这是可连续操作的移动 App 交互原型，包含首页、会话、任务、记忆、我的五个主入口。完整源码、素材、画板与运行说明都保存在这个仓库中。

- [在线体验完整 App](https://oops-app-demo-hyl-20261008.giftedprofessor516.chatgpt.site/)
- [在线查看记录体验改进画板](https://oops-app-demo-hyl-20261008.giftedprofessor516.chatgpt.site/record-improved.html)
- [在线查看完整界面画板（首版94页）](https://oops-app-demo-hyl-20261008.giftedprofessor516.chatgpt.site/board.html)

画板收录 **94 个独立界面**：首页 6、会话 20、任务 25、记忆 21、我的 22。一些业务页面已合并为标签页或底部面板，不重复计数。画板支持分组、搜索、缩放，点击截图可进入对应 App 页面；截图来自走查后的状态，首次进入时可通过操作生成自己的成果和回执。

## 体验一条完整流程

1. 首页点击「开始记录」，选择会议、日常、灵感或练习后点击「现在开始」；名称、项目和参与者可稍后补。完整会议准备是可选入口。记录控制跨页可达；结束前先暂停输入，沿用准备时的保留偏好，原话与私人便签分别选择。结束后进入「概览」，先看结果，再逐项核对结论、待办、身份和记忆候选。也可直接打开内置的「产品头脑风暴」。
2. 进入会话关联的任务，核对目标、本人责任、期限和验收条件，再确认承接。承接工作后，助手不会自动启动。
3. 普通行动可以记录真实进展，并填写实际结果直接完成。需要助手时，打开「助手准备」，选择真实资料、产出方式和额度，再允许这次个人草稿准备。内置 KPI 任务可生成框架文档和六页 PPT，支持预览、编辑与版本比较。
4. 缺少资料时补充附件或提出问题；需要修改要求时保留原任务并重新核对。停止助手不会取消业务工作。
5. 准备消息、邮件或日程，正文与附件绑定实际成果 ID 和版本。编辑具体对象与时间，核对本次全文后生成模拟回执。交付任务另行选择成果、核对标准并填写交付说明；核对助手草稿不会自动完成业务工作。

任务列表可切换「待我处理」「我的待办」「助手工作」。记忆、人物、项目、共享范围、工具连接及设备入口均可从对应主导航继续体验。

## 数据与演示范围

操作数据在浏览器允许时保存在当前浏览器的 `localStorage` 中，刷新后保留；不同浏览器或不同地址不共享数据。清除站点数据会回到初始示例。浏览器禁用存储时仍可体验本次页面中的操作，刷新后不能保留。

录音与转写、AI 生成、消息和邮件发送、日历提交、设备配对及外部工具连接均为本地示例，没有接入真实服务。界面可操作的表单校验、任务状态、成果编辑、权限范围与模拟回执用于验证流程；回执不代表真实发送或真实日程创建。

## 开发与构建

使用 Node.js 22.18 或更新版本及 npm。克隆私有仓库时，需要使用拥有访问权限的 GitHub 账号。

```sh
git clone https://github.com/zabr1314/oops-app.git
cd oops-app
```

在项目目录安装依赖并启动：

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 8796 --strictPort
```

本地 App 位于 `http://127.0.0.1:8796/`；完整画板与新版记录画板分别位于同地址下的 `/board.html` 和 `/record-improved.html`。

生成生产构建并在本地预览：

```sh
npm run build
npx vite preview --host 127.0.0.1 --port 8797 --strictPort
```

生产预览使用 `http://127.0.0.1:8797/`，画板位于同地址的 `/board.html`。构建输出在 `dist/client/`，以上命令不会发布到线上。

检查移动运行时与部署资源：

```sh
npm run check:runtime
npm run build
npm run test:sites
npm run test:logic
```

当前使用 React、TypeScript 和 Vite。应用页面位于 `src/features/`，导航和状态入口位于 `src/Prototype.tsx`，共享数据与演示种子位于 `src/store.tsx`，品牌素材和画板位于 `public/`。修改页面前请阅读 `AGENTS.md`，保留其规定的移动运行时。

线上体验由 Sites 托管，`.openai/hosting.json` 保存现有站点标识，不含访问密钥。推送代码到 GitHub 不会自动更新线上体验，发布网站需要单独完成。依赖目录、构建输出、测试临时输出和环境变量文件不进入仓库。

## 2026-10-08 会话与跨模块联动更新

会话列表优先活动记录与待核对内容，最近记录按日期分组，项目、类型、阶段和归档筛选收进底部面板。详情固定四个入口：活动记录显示「现场、原文、资料、行动」，结束记录显示「概览、原文、资料、行动」。概览区分只读结果与修改；核对队列支持逐项处理和稍后处理。

点击原话先打开阅读操作面板，可以修订、关联行动、留下候选记忆或按当前片段查询本地资料。跳转按准确片段 ID 定位，返回保留位置。资料可以直接添加到当前会话；手工行动保留会话关系，不虚构原话出处，同一来源优先打开已有任务。会议、日常、灵感和表达练习显示各自相关入口。

结论、问题、便签、准备表单及其他编辑草稿跨页保留；页面草稿使用当前标签页的 `sessionStorage`，浏览器限制存储时降级到内存。正式保存的数据继续使用原 `localStorage`，升级不重置已有记录；旧 Recall 片段迁移为独立保存快照，不因短期窗口清空而失效。

任务依据真实目标、资料和验收标准生成本地草稿。最新成果版本单独验收，旧验收留在历史。来源、资料、共享范围或授权变化后，停止原生成请求，旧成果保留待复核，失效内容退出团队回答和共同导出。候选记忆可以连续核对；人物姓名和声音许可分别确认，角色设置变化产生待核对背景，不覆盖已确认旧记忆。回答方式、长度与关注点用于当前本地建议组织。

## 2026-10-08 任务体验更新

任务列表保留「待我处理、我的待办、助手工作」，分别按处理原因、日期和准备状态分组。本人负责、本人提出及本人跟进可分别筛选；首页提醒和任务角标沿用同一个关注规则，已取消、已拒绝和已完成的工作退出队列，助手失败进入待处理。转交同意后仍可按设置的时间继续跟进。

详情固定「概览、资料、成果、记录」与当前阶段的主操作；更多操作放进底部面板。本人新建的普通待办直接进入待做，会话候选和他人交办仍需核对承接。普通行动支持人工结果完成；交付支持保存本人交付物或助手草稿，再针对明确版本验收。

助手准备合并资料选择、五种产出方式、允许范围和额度：资料整理、回复草稿、行动清单、文档、文档与 PPT。每次准备固定所选资料、原话、补充说明、产出、费用和版本快照；修改范围、来源或预算会停止旧请求。草稿保存后，原业务进度保留。

问题分别保存待回答、已回答、已解决、实际答复与下一次跟进。转交保存原业务状态及请求 ID，撤回或婉拒精确恢复原阶段。成果可比较实际正文的新增和删除；旧来源失效的版本不能仅靠更新任务来源继续发送。

沟通正文和附件版本共同更新；可以明确保留原稿及原版本，或重新起草并保留历史。最终确认固定当次全文、附件和对象，模拟回执不会被后来编辑覆盖。任务、资料、旧成果与通信草稿均保留原有数据。
