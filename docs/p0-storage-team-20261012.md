# P0 保存策略与团队入口实施记录

日期：2026-10-12。本文记录当前代码已经实施的内容与验证边界，供本轮最终交付使用。GitHub、公开网站和飞书意见表的最终同步由主任务确认；本文不代表线上服务已经部署。

## 实施依据

本轮落实 `AGENTS.md` 与 `docs/feedback-decisions-20261012.md` 已定稿的两项 P0：日常/会议保存规则，以及团队入口收敛。继续沿用 gifted-professor 已合并的 Android、录音、会议归档、任务与执行链路，由前端适配已有能力，没有另造后端或把公开演示直接连接个人执行端。

## 日常：最近5分钟临时缓冲

- 新记录默认进入日常方式。完整原音与临时全文以最近5分钟为边界；暂停、结束与取消沿用已有记录控制。
- React 原型的示例全文在内存滚动裁除；写入浏览器存档和重新载入时再次清理，临时全文与源头草稿不写成全场归档。滚动失效和停止同时清理对应页面内存草稿，避免旧文字在其他页面继续出现。
- 停止前先暂停并固定快照，取消恢复原来的运行/暂停状态。停止时先裁掉已经过期的缓冲，再清除剩余完整全文；不能通过后台延迟、再次停止或切换会议复活旧缓冲。
- 开启记忆时，React 停止流程最多留下3条私人、待确认候选；每条正文及必要短原话最多140字。候选不自动确认，不自动共享，也不自动承接或执行任务。用户独立填写的私人便签继续单独选择。
- Android 代码复用既有环形缓冲与记录引擎，日常不走全场录音存盘、会后上传链路；停止使用取消路径，防止迟到 ASR 内容重新回填已清空的缓冲。原生候选已具备核对与舍弃入口；实际设备行为仍需联调确认。
- 日常允许经授权的云端即时 ASR/分析，不等于允许长期存档，也不承诺完全离线。公开 React 原型只有示例输入，不打开真实麦克风。

## 会议：明确保存与独立到期

- 新正式会议需要用户明确选择云端保存；原声和全文分别默认30天，分别可选7/30/90天。默认变更用于新记录，不追溯删除已有无新策略合同的历史会议。
- 日常转会议新建会议 ID，从切换时开始保存。React 中此前仍有效的缓冲需额外勾选才纳入，默认不纳入；Android 当前切换从新会议开始，不复制此前日常缓冲。两端均不把日常聆听默认为会议存档授权。
- 前端保留分项存储状态，原声到期不同时删除仍有效的全文。全文到期会清理原话自动摘录、相关全文缓存、修订原始正文与回收站副本；恢复记录不能重置原合同的时钟。
- 后端沿用既有会议与录音归档，新增版本化合同、独立到期时间及清理逻辑。新客户端核对 `archive_policy_version:1`；新合同必须包含模式、明确确认和开始时间。重复请求不续期，修改合同冲突、未确认保存及过期资产由真实接口返回对应错误，客户端按资产类别停止无效重试。
- 独立确认的摘要、已保存任务及必要短证据与完整原文分开保留。React 对新任务、刚确认的记忆和结论固定短证据；后端提供明确确认的独立保留接口，原话上限280字，摘要与所选短依据绑定。不同端的上限按各自当前契约执行，不能当作全文仍存在或原音仍可播放的证明。
- 完整原文自然到期与用户主动修订、删除、撤回共享分别处理：前者保留有效独立短证据，后者仍撤回受影响的派生授权与旧成果的当前资格。手工任务、人工摘要不因到期被自动改写；旧成果和外部回执保留为历史，不承诺删除已经发布到第三方的文档副本。

## 团队入口：围绕项目和具体对象共享

- 首版不建设独立团队门户。首页个人视角取消强空间切换；历史共享视角保留回到个人内容的明确入口。
- 创建/加入团队、邀请成员与本地角色模拟退出主要路径。设置保留简洁的“内容范围与共享”“协作与共享”“已共享内容”入口，不把本地角色显示当作真实权限。
- 项目背景、历史决定、会话和同一任务引用继续由记忆→项目及会话承接；共享由具体会话、记忆、资料等对象明确选择，并能撤回。
- 保留已有对象 ID、项目 API、空间绑定、分空间草稿和 private/shared 边界；历史范围仍可查看，不删除旧成员历史或已有内容，也不因选择范围隐式创建、加入团队或扩大授权。
- 本轮没有实施第五导航“我的”改为“设置”的 P1 调整。
