# 网页端（React）按「Oops 设计语言」改版（2026-10-13）

安卓 H5 改版之后，用户要求网页端「一起改了」。范围是 `src/` 下的 React App（体验中心里的「体验 App」、两份画板的实屏都来自它），以及包着它的体验中心、安卓流程预览页和两份画板的外层配色。设计语言与安卓 H5 相同，权威来源是设计系统 [Oops 设计语言](https://claude.ai/artifact/3CTw3hmM1WXNBxmALvaLxh)。只改外观、交互和动效，不改业务规则、数据、路由或保存策略；受保护的移动运行时文件（`src/App.tsx`、`src/main.tsx`、`src/styles.css`、`src/mobile/` 等）一律未动。

同一天做了两轮：第一轮换上令牌、噗噗和基础动效；用户随后指出「很多都没用设计语言里面的效果」，第二轮按设计系统自己的组件样式（`components/bundle.css`）逐个补齐组件效果，并按用户的决定把导航改成四个入口。下面写的是最终状态。

## 导航（用户 2026-10-13 决定）

- 底部是悬浮胶囊（左右 16px、距底 16px + 安全区、高 64px），入口是 **首页、会话 | 录音按钮 | 任务、记忆**。录音按钮按设计语言 TabBar 的 center 凸起在正中，左右各两个入口。
- 选中项是浅紫小胶囊，图标换成 Phosphor 双色调版本（描边 + 20% 同色填充）并弹一下；标签 11/14·700。任务数角标按 Badge 规范是 danger 红底、2px 白圈，出现时弹一下。
- 「设置」移出导航，放到首页右上角（通知旁边的齿轮 IconButton）。settings 路由、旧深链接和设置里的入口都不变；设置页左上角是返回，回到首页。
- 这取代了此前定稿的「首页／会话／任务／记忆／设置」五导航。用户先后否定了五个入口时的「左三右二」和「录音按钮放在胶囊右侧」，最后决定合并为四个入口。`tests/settings-navigation-p1.test.mjs` 与 `tests/boards-integrity.test.mjs` 已同步改为检查四个入口、录音按钮和首页的设置入口。

## 录音按钮与录音条

- **录音按钮**（`src/ui.tsx` 的 `RecordButton`，同设计系统 RecordButton）：
  - 待录：麦克风 + 静止的浅紫光晕，点它进入原有的「开始一段记录」。
  - 录音中：白色圆角停止方块，两圈光晕匀速呼吸，点它进入原有结束流程（先暂停，再确认保存范围，取消就恢复）。
  - 暂停：麦克风 + 灰色光晕，点它继续。
- **录音条**（`RecordingControls.tsx`）：
  - 状态改成设计语言的 RecIndicator 胶囊：录音中红点每 1.2 秒闪一下，暂停时是静止的灰点，文字一律正文色。
  - 其他页面的紧凑态只放与录音按钮互补的一个操作：录音中放「暂停」，暂停时放「结束」。暂停与结束始终都能一点到达。
  - 展开态和会话现场仍是完整的暂停、标记重点、结束三个按钮，按设计语言录音页的样子排成三个带文字的圆形按钮。展开状态不跨页面或分栏继承（沿用定稿）。
- 首页记录卡和会话现场的状态行也换成同一个 RecIndicator。

## 组件效果（按设计系统组件样式）

- **按钮**：按下缩到 0.96，松手回弹；quiet 改为 ghost（透明 + 主色文字）。
  - 每屏一个渐变：页面上的渐变就是导航的录音按钮，所以页面自己的主操作改用 ink 深色按钮，卡片里的按钮用 secondary。
  - 底部面板盖住导航，面板里的主操作仍用渐变（52px 大号）。
  - 危险按钮在页面上用浅色，只有面板里的确认才用实色。
- **IconButton**：顶栏按钮是 surface 白色圆片 + 浅阴影，按下 0.9。
- **Chip**：未选中是填充色；选中变成主色实底，并弹出一个对勾。
- **分段控件**：一颗白色滑块带回弹滑到选中项（`Tabs` 输出 `segmented-thumb`）。
- **开关**：52×32，开启时轨道淡入渐变，按住时圆钮被压扁变宽，松手带回弹滑过去。
- **复选框**：圆角方块，勾选时填主色，对勾弹出。
- **Tag**（`Badge`）：24px 高、圆角 6；成功、提醒、危险三种状态色自带图标。
- **输入框**：52px 高、16px 字，聚焦时主色描边 + 浅紫外圈。
- **列表**：卡片里的分隔线从文字处开始；设置页各分组的图标块用不同状态色。
- **Toast**：深色胶囊，停留 4 秒。小失误（「先…再…」、缺少输入、来源变了）带 oops 表情的噗噗；保存完成带开心的噗噗。删除、清除、撤销和普通告知不放噗噗。
- **空状态**：带 `mood` 时是 120px 噗噗 + 24/900 品牌标题；权限边界和错误仍用图标。
- **Loader**：三颗果冻点依次跳起，落地时压扁。用在助手准备中、问答整理中、聆听判断中三处等待。
- **Waveform**：竖条 3px 宽、间隔 3px，颜色从 brand-jelly 渐变到 primary，录音时轻轻起伏。用在首页记录卡、智能聆听、声音身份。
- **ProgressBar**：10px 高，渐变填充 + 高光线。
- **转写行**：说话人头像按人固定颜色（「我」固定 speaker-1），正文 16/26，当前句铺浅紫。
- **首页头卡**：dusk 主角卡（墨→靛→宝石蓝→主色）。卡片上不加光晕，果冻光泽只给噗噗。
- **「说给 Oops 听」**：页面上的渐变已经是导航的录音按钮，所以这里的麦克风改为白色果冻圆 + 浅紫光晕。

## 第一轮保留下来的部分

- **令牌**：放在 `src/prototype.css` 开头的 `:root` 上，因为底部面板渲染在 `.oops-root` 之外。拉丁字符用 Nunito（`public/fonts/`，附 OFL 许可）。原来约 300 个零散色值都换成了令牌。
- **图标**：按文字颜色着色的蒙版（`Icon` 输出 `<span class="icon">`）。新增的 Phosphor 双色调和粗体图标（导航、对勾、状态、麦克风）放在 `public/icons/`。
- **噗噗**（`src/Pupu.tsx`）：与安卓同一份描图，只在情绪时刻出现，每屏最多一只。
- **动效**：页面上浮淡入、Toast 和录音条弹入、新转写句子滑入一次。系统「减弱动态效果」打开时，所有循环动画、缩放和回弹都停止。
- **顺带修复**：任务「问题与跟进」页的标题曾被按钮挤成竖排。

## 验证

- **测试**：全部通过。
  - 前端逻辑 323 项、原生 H5 界面 70 项、原生流程预览 7 项、画板一致性 7 项、站点资源 4 项
  - 运行时完整性 28 个文件、TypeScript 检查、生产构建
- **对比度**：194 个页面和状态逐页检查了 3983 处可见文字（不含禁用控件、面板遮罩下和导航背后的文字），全部达到 WCAG AA。
- **减弱动态效果**：打开后，记录中的首页和任务页没有持续运行的动画；关闭时只有录音红点、录音按钮光晕、噗噗呼吸和聆听声波在循环。
- **截图**：按 `screenshots/capture-plan.json` 用真实渲染重拍全部 194 张实屏（iPhone 外框，1280×720 视口），并重建两份画板。
