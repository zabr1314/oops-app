# 网页端（React）按「Oops 设计语言」改版（2026-10-13）

安卓 H5 改版之后，用户要求网页端「一起改了」。范围是 `src/` 下的 React App（体验中心里的「体验 App」、两份画板的实屏都来自它），以及包着它的体验中心、安卓流程预览页和两份画板的外层配色。设计语言与安卓 H5 相同，权威来源仍是设计系统 [Oops 设计语言](https://claude.ai/artifact/3CTw3hmM1WXNBxmALvaLxh)。只改外观、交互和动效，不改业务规则、数据、路由或保存策略；受保护的移动运行时文件（`src/App.tsx`、`src/main.tsx`、`src/styles.css`、`src/mobile/` 等）一律未动。

## 改了什么

**令牌与样式**（`src/prototype.css`）
- 文件开头加入与安卓相同的令牌（画布 `#f2efff`、主色 `#6449ea`、正文 `#121130`、次要文字 `#4b4869` / `#686589`、圆角、阴影、缓动），并放在 `:root` 上，因为底部面板渲染在 `.oops-root` 之外。拉丁字符用 Nunito（`public/fonts/`，附 OFL 许可），中文沿用系统字体。
- 原来分散在 `prototype.css` 和 `src/features/*.css` 里约 300 个零散色值，按用途换成令牌：文字色 → 正文 / 次要 / 主色文字 / 状态色，背景 → 白色表面 / 画布 / 填充 / 主色浅底 / 状态浅底，边框 → 分隔线。替换后所有文字都达到 WCAG AA。
- 文件末尾是「Oops 设计语言 · 网页端」设计层：按钮、卡片、列表、徽标、芯片、分段控件、表单、开关、提示、底部面板外观、Toast、悬浮胶囊导航、录音条。通用组件规则用与原样式相同的权重写，所以各页面自己的尺寸规则（如提醒卡里的三按钮行）仍然生效。
- 每屏一个渐变：页面主操作保留渐变，卡片里的主按钮改为纯主色；红色只表示「正在录音」（录音红点、结束按钮）。
- 图标改为按文字颜色着色的蒙版（`src/ui.tsx` 的 `Icon` 输出 `<span class="icon">`），选中、禁用、危险状态自动跟随颜色。
- 内容在悬浮导航下方滚动时有一层画布色渐隐，最后一行不会和导航叠在一起。

**噗噗**（`src/Pupu.tsx`）
- 与安卓 `pupu.js` 同一份描图：右上偏的圆角三角，不是圆形。
- 只在情绪时刻出现、每屏最多一只。`Empty` 新增 `mood`：还没有内容时睡着（sleepy），搜索或筛选没结果时思考（thinking），内容已移除、没找到时 oops，核对完成时开心（happy），等待第一段原话时聆听（listening）。权限边界、空间切换、错误类提示不卖萌，仍用图标。
- 首页：记录进行中换成「聆听」姿态，草稿准备中「思考」，准备失败「oops」。暂停、待核对和空闲时沿用官方原图及原有状态动效，判断逻辑 `homeMascotPresentation` 未改。

**动效**
- 每次进入页面时内容上浮淡入（固定的顶栏、分栏、导航不动）。
- 主导航选中项弹一下；按钮、芯片、卡片按下时果冻回弹；Toast 和录音条弹入。
- 刚听到的新句子从下方滑入一次（`TranscriptCard` 按 `receivedAt` 判断），之后打开页面不会重复播放。
- 系统「减弱动态效果」打开时，以上动画全部停止，噗噗和录音红点不再闪动。底部面板的弹出动画属于移动运行时，保持原样。

**顺带修复**
- 任务「问题与跟进」页：标题旁的「新增」按钮把标题挤成了竖排，现在标题和按钮各占自己的宽度。

**外层页面**
- 体验中心（`public/showcase.css`）、安卓流程预览页（`public/native-flow.css`）以及两份画板（`scripts/build-boards.mjs` 内联样式）的配色换成同一组令牌，`theme-color` 改为主色 `#6449ea`。版式与交互不变。

## 验证

- 前端逻辑 323 项、原生 H5 界面 70 项、原生流程预览 7 项、画板一致性 7 项、站点资源 4 项、运行时完整性 28 个文件、TypeScript 检查与生产构建均通过。
- 按 `screenshots/capture-plan.json` 用真实渲染重拍全部 194 张实屏（iPhone 外框，1280×720 视口），并重建两份画板。
- 重拍前后逐页对比无障碍快照：除时钟外，只有「文档角色 · 可修改并明确应用的草稿」一页不同。旧截图停在第 1 步，因为第三次点击被固定的录音条挡住、没有生效；新截图按清单走到了可编辑草稿。截图脚本现在遇到被固定栏遮住的按钮，会先把它滚到中间再点。打开底部面板时，快照同时记录页面和面板，与旧档一致。
- 194 个页面与状态逐页做文字对比度检查（不含禁用控件和面板遮罩下的文字），共 4226 处文字，全部达到 WCAG AA。
