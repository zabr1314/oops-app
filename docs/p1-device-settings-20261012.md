## 第2条：设备开机后的聆听与恢复

主要入口为“设置→设备与声音入口→添加设备/设备详情”；原设备列表、按键/指示灯偏好、离线记录、解除配对等入口保留。

| 操作或状态 | 已实现的前端结果 |
| --- | --- |
| 首次配对 | “这台设备开机后自动聆听”默认未选，按设备单独保存；切换设备重置本次选择。失败可重新扫描，配对成功后可查看设备。 |
| 配对或保存偏好 | 只保存选择，不直接开始录音，不注册声纹、确认人物或共享内容。关闭自动聆听不替用户结束已有记录。 |
| 收到示例开机信号 | 设备已配对且明确选择自动聆听，权限、服务和安静时段条件允许时，进入私人日常临时记录。重复信号沿用当前记录。 |
| 权限缺失、后台受限、断连、安静时段、服务不可用 | 展示具体原因；设备自己的进行中日常暂停。把条件改回就绪只恢复条件，之后需明确恢复。 |
| 用户暂停后重连 | 保留暂停选择；明确继续沿用同一个日常session，不重复创建。 |
| 用户停止后重连 | 保留停止选择；明确恢复才建立新的日常记录，仍不自动变成正式会议。 |
| 已有会议或其他活动记录 | 原记录优先，设备让位；不新开第二场，不改变原记录ID、模式、云保存合同或内容。活动状态不一致时先核对。 |
| 解除配对 | 关闭该设备自动聆听选择，仅暂停该设备拥有的日常记录，已保存内容保留。 |

React设备详情提供条件选择、示例开机/重连、明确恢复、暂停以及停止检查重点；停止复用现有结束面板，取消沿用原恢复语义。自动日常仍遵守最近五分钟全文缓冲、停止清除、私人候选待确认；不隐式开启会议云保存、长期记忆、任务执行或共享。

设备所属的个人安静时段独立于正在浏览的内容范围。由设备进入“聆听与安静时段”时编辑本人偏好，保存或取消返回同一设备；切换到共享内容不能绕过个人安静时段。五分钟来源及镜像清理保留设备归属，跨页暂停/结束仍能更新设备的暂停/停止状态，缓冲到期后也能沿用正确记录明确恢复。

### 示例与真实状态隔离

- React配对选择是本机示例偏好；设备开机、权限和服务运行条件只在内存中保留，刷新回到尚未收到开机信号，不拿旧运行状态证明真实设备在线。画板场景使用既有隔离数据，不能覆盖自由体验中的用户数据。
- Android H5设备页使用独立内存模型；配对、开机、暂停、停止与恢复不向原生收音桥发指令，也不写真实设备设置。现有原生记录始终优先，示例不能改变或恢复它。
- React使用本人配置的北京时间安静时段；Android设备示例保存本次体验的时段输入，并由用户手动选择“安静时段”条件，尚未自动随系统时钟切换。输入校验、取消和偏好编辑均不隐式开始记录。
- 页面状态、恢复按钮和示例会话不证明麦克风、蓝牙、真实ASR或后台服务已经运行。公开体验不加入真实服务凭据。

相关源码：`src/deviceStartupLogic.ts`、`src/features/DeviceStartup.tsx`、`src/features/DeviceStartup.css`、`src/features/Listening.tsx`；跨页停留状态及运行时隔离由`src/Prototype.tsx`、`src/storagePolicy.ts`、`src/viewState.tsx`承接。Android独立模型为`android/app/src/main/assets/web/device-listening-demo.js`。

## 第16条：由“我的”收敛成“设置”

React五导航为首页、会话、任务、记忆、设置；第五栏使用已有齿轮素材，保留`settings`路由。设置首页移除重复的大个人档案和关注内容展示，将原11个目的入口各保留一次：

| 分组 | 保留入口 |
| --- | --- |
| 账户 | 账户与安全、用量与方案 |
| 身份与助理 | 身份与角色、助理偏好、我的声音身份 |
| 设备与聆听 | 设备与声音入口、聆听设置 |
| 工具与通知 | 工具连接、通知与自主等级 |
| 隐私与共享 | 隐私与数据、内容范围与共享 |

账户称呼和角色只作为对应入口的简洁提示，身份/偏好仍使用原编辑入口与同一套数据；保存期限、共享、文档角色、声音样本等旧深链接继续可达。改变页面编排不会修改已有对象ID、内容范围、连接许可或设备选择。

Android H5第五栏同样显示设置，保留原`me`等路由及本人选择、声音许可、收音与服务连接、诊断等实际动作；按其现有能力编排，不宣称已拥有与React完全相同的11个独立页面。内容、人物、项目和检索继续留在记忆，不改为泛动态流，也不另建团队门户。

相关源码：React的`src/Prototype.tsx`、`src/features/MemorySettings.tsx`、`src/features/MemorySettings.css`；Android H5的`app.js`、`app.css`和`index.html`。
