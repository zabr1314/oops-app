# 会后结果自动同步到手机（2026-10-16）

用户明确选择先实现App内自动同步：App打开时获取，整理好后提示，离线后恢复网络或下次打开自动补取；本轮不做退出App后的系统推送。用户另行明确授权正常结束并保存当前正式会议，再覆盖更新主版。

## 实现

- 沿用原生鉴权通道与服务器现有 `history.list` / `history.minutes` 只读接口，没有另建结果库、执行器或模型接口。查询不重新生成纪要，不发送飞书，不创建任务或日历，也不替代人工核对。
- 新增H5 `minutes-sync.js`，前台每20秒核对现有最近会议列表；同屏最多2个纪要读取，待整理结果约10秒再核对，已就绪结果约60秒重新核验。间隔是查询计划，不是从收音到结果的时延保证。
- 自动获取已结束、至少5句且全文未过期的会议；本人明确打开的旧会议也可继续跟随。列表沿用原接口最近30条范围，未把日常五分钟临时内容纳入完整会议同步。
- 会话卡显示“整理中／纪要已同步／同步待重试”；批量完成合并提示，不自动跳页。结果更新只修改纪要区域和状态，保持当前编辑面板、输入和阅读位置。
- 后台停止自动读取，返回前台重新核对。断网或读取超时使用有上限的退避重试；来源修订、删除、到期、后端更换及迟到回包均有清理或隔离。完整纪要正文只在当前App页面内存中使用，不新增永久离线副本；离线恢复后再从服务器补取。
- 原模拟预览不启用真实自动同步，也不引入服务凭据。
