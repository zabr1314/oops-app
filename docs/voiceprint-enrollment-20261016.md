# 安卓声纹录入跳页修复 · 2026-10-16

用户确认：安卓安装版点开始录入后跳到首页/录音页，无法完成录入。

## 根因与改动

原生 `voiceprint.record` 先进入声纹 recording 状态；没有活动收音时启用手机麦克风。H5 `setState` 收到 capturing 从 false 到 true 后无条件 `go('live')`，`go` 关闭当前声纹面板，`closeSheet` 又发送 `voiceprint.cancel`，临时样本随之清除。

- 保留普通收音的录音页导航；当前声纹面板打开时不执行自动跳页，因此开始录入仍停在原入口。
- 声纹状态比较排除 elapsedMs，仅更新录音时间、进度和连接提示，避免每个音频帧重建朗读面板。阶段、质量、失败、保存回执与匹配结果仍重新渲染。
- 录入中保留结束按钮，增加单独放弃当前样本入口。
- 沿用原生 30/10 秒限额、本人独立许可、质量检查、明确保存、sample_id 与版本回执；没有更换后端、改动采集/保存策略或真实声纹。
