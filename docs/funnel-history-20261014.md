# 蜘蛛页与历史会议处理记录

本轮按用户要求保留原深色蜘蛛页，对齐实际部署的后端，并直接读取已有项目存储。原公开体验中心继续使用示例，私有历史入口为 `https://giftedprofessor.xyz/oops-meeting/history/`。网页读取不运行 Jev、DeepSeek、ASR 或飞书操作。

## 历史真实性

- 后端目前使用 `meetings/*.json` 和 `feishu/state.json` 保存会议与纪要；网关直接只读这些现有文件，没有另建一份会议信息库。
- 本轮只读核对到 12 场、726 句、12 份已存纪要。历史原话只有最终标签，没有逐句概率、模型、上下文和时延。页面明确“仅存最终标签”，灰色表示历史步骤缺失。
- 10 份原纪要保存 `runs=3`，表示成功参与投票的份数，不等于精确调用/重试次数。最终读取时 11 份纪要可显示，1 份当前无可用结果而被收起；不得拿旧纪要当当前结果。
- 原 `replay_meeting.py` 重新执行模型的结果属于“重新分析”，不冒充会议当时的记录。已有离线文件仍可本机打开，禁止把私有回放提交或发布到公开站。
- `GET /api/pipeline` 只提供部署源码的配置、哈希及读取时间。它与该场历史记录分开，不把源码里存在入口当作运行时已经启用或该场执行过。只有此无私密数据接口开放无凭据 CORS；会议接口不开放跨域读取。

## 只读访问

独立 `oops-history.service` 监听回环 8797，经原主机的 `/oops-meeting/history/` 路由提供页面。它不加载模型密钥，没有会议目录写权限，网络仅允许回环。未授权会议接口返回 401，错误范围返回 403。

查看凭据由服务器 CLI 签发，绑定明确会议 ID、只读用途及 最长 24 小时有效期；一次性邀请换取 HttpOnly、Secure、SameSite=Strict 的路径限定 cookie。只存邀请/会话的哈希。邀请不写 API URL、localStorage 或日志；页面交换后立即去掉 fragment。退出撤销服务器会话并同步清空内存和画布。邀请及含邀请的完整 URL 不进入文档、公开站或最终回复。

源删除、全文到期、身份/原话版本变化会使旧依据失效。浏览器每 30 秒及恢复焦点时重新只读核验，同快照保留播放位置；权限、来源或读取失败时清空旧历史。当前规则派生的事项和队列明确标注为重算，不冒充模型当时的中间过程。

## 后续真实轨迹

`ProcessingTrace` 只旁录原本已发生的分类调用，不增加模型请求。记录整句分类、实际小句判断、规则回退及质量复核各阶段，保留返回的概率、模型、耗时和明确输入来源；缓存命中不伪造一次新的调用。

未归档请求最多在 RAM 中保留 5 分钟；只有已有会议且目标原话完全一致时才附入同一会议文件。上下文必须逐句唯一绑定当前 ID/哈希，否则不保存副本。原话或身份变更时清除失效轨迹/上下文，全文到期时清理 `processing_trace`，不延长原保存合同。没有对旧会议补算历史轨迹。
