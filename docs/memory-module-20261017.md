# 记忆模块：会议／项目与个人

## 产品范围

用户明确将记忆分为「会议／项目」与「个人」。个人范围为本人身份、偏好、目标、经历，以及日常值得记住的事。

会议仍是原来的会话对象：一场会议集中承接录音处理后的原文、总结纪要、重点、决定、未决问题与行动。项目串联相关会议及人工确认的决定和任务；本轮页面不新增识别或纪要重分析请求。原列表接口已有的后台标题整理仍按既有行为运行，不能将读取列表泛称为绝对零模型工作。会议结果不会自动转为个人长期记忆。

个人手动档案与日常候选分开：手动档案由本人填写；日常候选沿用已有确认、摘要、本人改写和短依据链路。身份档案不修改任务身份、声纹许可或飞书身份。人物、灵感、收藏、模板等既有入口继续保留。

## 本地实现

- React 沿用当前本地会话、项目、记忆和来源保护。它仍是本地体验模型，不冒充 Android 真实纪要接口。
- Android H5 沿用 `history.list/open/minutes` 与项目接口，读取已有会议和纪要状态。会议列表当前接口最多载入最近30场，页面内检索只覆盖已载入内容。
- Android 手动个人档案使用新的独立本机私有存储，不改写录音、保存片段、后端会议或任务数据。不自动上传云端或给模型使用；浏览器模拟使用独立内存，刷新即清除。
- 新增、编辑和删除均等待原生回执。未知写入结果先读回核对，不自动重发或换 ID 创建另一条。编辑不存在的条目不能重新创建；失败不以空列表掩盖损坏的存储。

## 原生桥接

命令为 `personal.list`、`personal.save`、`personal.delete`，均带 `requestId`。`save` 带 `id/title/body/kind/create`；分类为 `身份/偏好/目标/经历/日常`，新建显式 `create:true`，编辑 `create:false`。标题最多100字、正文最多5000字。

回执 `personal.result` 包含 `requestId/action/ok`，成功读取带 `items`，成功保存带 `item`，失败带 `error`。条目含 `id/title/body/kind/createdAt/updatedAt`。时间为实际保存的毫秒时间戳。数据保存在 Android `noBackupFilesDir`，不进入系统自动备份。
