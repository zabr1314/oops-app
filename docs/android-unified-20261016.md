# Android 统一界面与安装包（2026-10-16）

用户要求安卓采用网页同一套界面和功能，并提供新版安装包；用户不知道旧签名位置。本轮复用同一份 React 页面与业务组件，新增真实手机运行层和原生桥，避免继续维护两套主界面。

## 页面与数据

| 模块 | 统一内容 | 安卓承接 |
| --- | --- | --- |
| 首页 | 紫色品牌、伙伴形象、开始记录、问答和继续工作 | 当前真实收音状态、服务记录；正式包不装入 initialData 示例 |
| 会话 | 相同列表及现场/概览、原文、资料、行动四分栏 | 原生转写与会议、已保存纪要读取，原话精确定位；复杂核对/交付仍复用既有确认与恢复流程 |
| 任务 | 任务列表、本机待办和个人草稿流程 | 正式服务任务只读投影，负责人/来源与外部操作在原生核对中处理，不用本机状态冒充飞书回执 |
| 记忆 | 相同内容、人物、项目、个人理解与人物记忆 | 本机信息分账号/服务保存；账号已有记忆须在同步管理里核对，不按同名自动合并 |
| 设置 | 相同五导航与设置分组 | 本人账号、设备、麦克风、服务连接及隐私采用真实原生权限入口 |

同一套 JSX/CSS 编译到 APK，不放模拟手机外框、设备选择器、假状态栏或假键盘。安卓使用系统键盘、真实安全边距和滚动，键盘展开时录音条让位；原受保护网页运行时 28 份文件保持原哈希。正式入口缺原生桥只呈现空态，隔离预览必须显式 `native-preview=1` 才加载 mock。

原有复杂核对、声纹、飞书交付和操作恢复保留在受控打包页面中，以相同品牌呈现并提供“返回 Oops”；不移除旧的确认、防重、来源和账号校验。该页作为顶层页面使用原生桥，不给第三方 iframe 扩大原生权限，回跳仅接受本地白名单形式的路由 hash。

## 真实收音和保护

手机麦克风支持真正暂停/恢复：暂停释放 AudioRecord，ASR 排尾后恢复同一个 session ID、保存合同和单调样本时轴，不调用停止冒充暂停、不写结束标记。WAV/录音豆回放和真实录音豆未声明支持此暂停能力，界面按能力显示。录音/暂停/最终转写收尾期间切换服务 URL、访问凭据或 mock 状态，会在保存任何字段前整次拒绝，保留原设置与会话。

真实历史与任务的请求按服务代次和本次读取校验；失败、撤权、删除时移除旧正文，删除后的迟到回包不能复活会议。远端正文和引用其来源的副本不写入新的本机缓存。账号或服务变化撤回旧背景/草稿；scope 变为未就绪时同样立即清空仍在编辑的私人表单并返回首页，只有首次建立范围保留原深链接。未知归属内容不会迁到新账号。新建的本机人物、记忆和草稿可在同一明确范围重新打开读取。

## 构建和安装范围

新增 `native.html`、独立 Vite 原生配置、`scripts/build-native.mjs`，生成完整 `unifiedWebAssets`；Gradle opt-in 使用这份资产根，旧手写 web 不与新入口冲突。工具链在工作目录隔离准备，使用官方 JDK21、Android SDK 37.2、build-tools 36 和 Gradle 9.8，不改全局 Java/SDK 配置。

独立包参数：`com.oops.app.unified`、显示名称「Oops 新版」、版本 `0.2.0-unified`、versionCode `2026101601`。没有旧签名私钥，不能保证覆盖旧包；独立安装保留原 `com.oops.app` 及其数据，旧内容不自动迁移。新版专用调试签名保留在本机忽略的工具目录，后续升级新版必须复用。两版共装遇到飞书授权应用选择时，应选择「Oops 新版」。本轮不替用户安装或卸载手机应用。

当前目录没有原实时 ASR 构建配置和 Anker 私有 AAR。只读查询没有已连接授权手机、GitHub Releases 或 Actions APK 可供安全复用。无凭据构建时手机收音/本机流程可运行，但实时转写为未配置，界面明确提示不会产生实时文字；服务地址、账号与访问权限需要重新连接。没有私有 AAR 的包不含真实录音豆 SDK，只提供手机麦和已明确标注的测试/模拟来源。未冒充已完成真实设备/生产链路验收。
