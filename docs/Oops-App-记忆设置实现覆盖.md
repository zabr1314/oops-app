## 真实数据联动与范围

- 所有主要对象均直接更新共享 `AppData`：memories、people、projects、tasks、sessions、notifications。候选核对、模板生成、工作流待办、声音纠正、日历同步和回收恢复可从其他主导航继续查看。
- 辅助本机配置保存在 settings.retention（角色、空间成员、资料条目、复盘、操作记录等）和 settings.toggles（读取/写入、声音共享、设备反馈）。期限页只展示 3 个正式期限。
- 个人空间可见自己的本机内容；团队或新空间仅显示归属该空间的共享记忆与人物。详情同样有访问保护，私人备注不进入团队视图；新空间不会只是换一个空间名。共享归属键为 memory-space:/person-space:/project-space:，既有共享归 Oops 产品团队。新待办写 task-space:。
- 分享来源若其会话未共享，团队内容页隐藏会话跳转。团队导出排除私人会话、私人转写与笔记；任务成果入口和导出按任务所在空间或共享来源过滤。
- 身份纠正只影响选中的转写片段，不把声音身份确认当成工作承接，不改变 TASK-021 负责人。

### 范围审计修正

- 声音身份核对/纠正限个人空间；团队深链不显示默认私人会话片段，也不提供修改入口。
- 冲突旧角色已使用与记忆列表一致的 visible 判定，团队看不到私人 MEM-001。来源选择进一步只列当前可见会话；私人原始来源可保留，但不展示标题或跳转，只有主动选择新来源才改写它。
- 项目编辑深链与详情共用空间归属保护；错误或已经移除的项目 ID 不会变成空白新建表单。
- 成长关联会话、项目会话计数、记忆出处和数据导出统一使用会话共享及空间归属判定，防止从其他来源入口列出私人会话标题。
- 任意候选不能替换个人角色记忆。替换选项与保存逻辑都要求处于 memory-conflict，且候选属于记忆类型的身份/角色冲突（初始 MEM-003），旧角色在当前空间可见并与候选不同。替换前把旧正文、标签、范围、确认状态、来源等完整快照存入 memory-history:旧记忆ID；原版本仅在个人空间的记忆详情可查看。
- 声音身份真实发生变化时，仅同一来源会话与时间段的记忆标为待复核；关联任务撤销执行授权、助手转为待授权、成果标记需复核并追加活动记录，原任务负责人保留。会话复盘同时标记需要更新。同一身份重复保存不撤销无关授权。

## 实质限制

以下不是已接通的能力，App 就近标记为示例或概念：真实声纹提取、麦克风声音采集、蓝牙硬件控制、音频播放/动态发布、真实工具 OAuth 与读写、云端处理、邀请邮件、登录与账户安全服务、后台监听/位置唤醒、自动期限清理、真实计费。项目资料目前可添加名称/链接条目，未新增二进制文件上传服务。空间成员权限是本机前端状态，真实服务端权限校验未实现。

已完成模块类型检查：`npx tsc --noEmit` 通过；移动运行时保护校验通过（28 个保护文件）。本模块没有改共享运行时、导航或受保护样式；浏览器联调由主代理进行。
