# Oops App 会话实现覆盖

实现文件：`oops-app/src/features/Sessions.tsx` 与 `Sessions.css`。本次使用现有共享 UIKit 和 store，未修改移动运行时。

## 已落地的交互

| 功能 | 实际交互与状态 | 路由 |
|---|---|---|
| 会话列表 | 关键词真实过滤标题/发言，类型、状态与项目筛选组合；空结果可清除筛选；归档、删除、回收恢复 | `sessions` |
| 创建与准备 | 选择会议/日常/灵感/练习，填写名称、项目、参与者、议程、保存方式和共享选择；校验后创建独立 Session | `session-mode`、`session-create` |
| 连续记录 | 全局 `useSessionRecorder()` 每秒更新时间、每4秒追加一段预设内容；切换底栏不影响输入；不同记录类型使用不同示例 | `session-detail` |
| 暂停、结束与后续 | Sheet确认暂停/结束，同步 Session.status 和 activeSessionId；结束生成复盘；可以选择保留片段；结束记录启动后续时创建新实体 | 记录详情内控制 Sheet |
| 会中五分栏 | 现场、转写、资料、任务、复盘可持续切换；我的视角与共同纪要分开 | `session-detail`、`session-transcript` |
| 会中资料 | 本地查询形成资料卡并加入本次资料；打开资料、查看出处时间、回到讨论、收藏与大屏预览 | `session-source` |
| 议程与提醒 | 编辑议程、推进当前议题；保存1—1440分钟计划，基于Session.duration持续倒计时/显示超时；最近3段文字匹配议题关键词并标明“规则提示”，可查看来源和忽略；思维导图、预算冲突核对 | `session-agenda`、`session-map`、`session-display`、`session-reminders` |
| 转写与回放 | 关键词/说话人真实过滤；示例时间轴逐条高亮，暂停与倍速；按任务传入的mode时间定位原话 | `session-transcript` |
| 修订与身份 | 编辑文字、敏感片段、删除确认；原文保存在私人修订历史，可恢复；纠正指定片段/同一匿名标签；仅相关候选标为待复核，不修改别的任务负责人 | `session-edit`、`session-identity`、`session-revisions` |
| 导入 | 粘贴文字或读取TXT/Markdown，逐行预览后创建真实本地Session；音频只读取文件元信息，不伪造转写 | `session-import` |
| Recall | 搜索和选择当前候选，私有保存独立Memory，或保留来源并建立独立Task草稿；清空/到期阻断旧保存；新窗口使用新ID、时间与新示例，旧选择不能恢复 | `session-recall`，保存/清空为Sheet |
| 日常、灵感与练习 | 日常便签和联系草稿；灵感核心观点/口播提纲；表达原话、改写和成长目标；中文/中英对照/English选择、语气偏好、手选情绪情境及反馈示例；可编辑改写并保存私人目标，日常/灵感草稿可形成独立待办 | `session-inspiration`、`session-growth` |
| 复盘与历史查询 | 当前来源整理复盘、保存个人记忆、查看关联待办与资料；历史问答按本地关键词返回匹配发言和可点击出处 | `session-detail`（复盘）、`session-history` |
| 导出与分享 | 导出预览、真实本地TXT下载/复制；可选个人内容；保存接收者和会话共享范围，逐份Check选择附加资料；团队/大屏/共同导出仅显示所选资料；撤销以后访问，共享视角隐藏私人便签/敏感发言 | `session-export`、`session-share` |

跨模块使用：`task-detail`接收Task.id；`memory-detail`接收Memory.id；记忆主入口为`memory`。任务/记忆来源可传入`{view:'session-transcript',id:sessionId,mode:sourceTime}`。

## 共享与保存规则

- 已有会话默认私有。团队内访问同时检查`shared-${id}`开关及`session-space:${id}`；旧的明确共享对象未指定空间时默认`Oops 产品团队`。新的共享范围写入当前团队，个人空间共享默认写入该默认团队。
- 团队查询与列表不使用敏感片段搜索结果，不展示私人复盘、修订历史与表达练习。新的私人记录、导入和Recall保存进入“我的空间”。
- `settings.retention`内还保存本地内部元数据：会话空间、议程进度、示例序号、Recall窗口开始时间、共享接收者、计划时长、逐资料共享空间/所选目录和已删除会话快照。设置界面应只列正式保留期限字段。
- 逐资料授权保存`material-shared:${sessionId}:${title}`开关、`session-materials:${id}`目录及`material-space:${id}:${title}`空间；源自敏感片段的资料不能共享，团队资料直达也校验。完整共享编辑在个人空间，团队只显示已选项。
- 恢复会话不恢复共享权限，受影响的派生内容保留待复核状态。日期显示使用`Asia/Shanghai`。
- 转写文字、敏感范围或删除发生变化时，仅命中同一会话/时间的记忆变为未确认并加入“待复核”；关联任务撤销授权、进入待授权并递增要求版本。既有成果和结果原样保留，成果附加待复核标记，旧生成任务失效；原文另存私人修订历史。

## 实质边界

录音、ASR、声纹、联网检索、真实库存、外部分享链接与发送均未连接服务。资料查询是本地示例与项目数据检索，回放只演示时间轴。音频/表格/PDF文件正文不解析。复盘、表达改写和口播提纲使用本地结构整理，不伪称模型生成。

议程提醒使用可解释的文字关键词规则，没有偏题评分模型。中英输出中的英文为可编辑结构示例，没有调用翻译服务；语气/情绪反馈来自用户手选情境，没有做真实声音或情绪识别。真正硬件投屏和来源片段拖拽范围选择未接通；大屏有本机预览，结束保留用明确片段勾选，Recall用当前窗口候选选择。

验证：整项目`tsc --noEmit`通过；`check:runtime`通过，28个保护运行时文件未修改。本代理按分工未打开浏览器；实际渲染和连续流程由根代理统一验证。
