# 可直接采纳意见的前端改进 · 2026-10-12

本轮承接飞书意见复核及用户继续实施的授权，完成下面七类可直接改动的前端内容。沿用已合并的 Android、服务器和飞书工作助手实现；没有把公开原型接到真实会议或外部执行服务，也没有替团队决定仍有分歧的保存、硬件和导航规则。

## 七类实际改动

| 类别 | 当前入口与操作结果 | 保留的边界 |
| --- | --- | --- |
| 1. 文档角色草稿 | 我的 → 身份与角色 → 文档角色建议。选择示例飞书文档，或粘贴本人选定正文；手动选一段依据，编辑称呼、角色与适用场景，明确核对后应用当前身份，再比较历史角色背景。首次使用不要求导入文档。 | 选择器与分析为本地流程。没有真实读取飞书文档，也没有任意文档自动角色分析。结构明确的本人描述可填入建议；不能明确提取时由本人补充。不按他人的职责认定自己的身份。 |
| 2. 工作助手类型入口 | 任务 → 助手准备 → 工作助手，按现有工作助手能力提供查资料、整理报告、做 PPT 三个入口，说明对应报告、飞书文档或 PPTX 的能力范围。个人正文、要点、行动步骤和汇报提纲仍使用原准备页。 | 不承诺任意格式或代码执行。当前页面没有提交真实工作；真实工作助手能力来自已有后端/机器人，不能把其已存在误写为 App 已接通。 |
| 3. 工作助手异常与已有结果承接 | 核对选定原话/资料及个人草稿范围后，分别体验离线等待、恢复在线、生成失败、交付失败和结果可查看。生成失败重新允许；交付失败重读同一请求结果。成果页提供已有服务文档/文件的承接位置及历史结果说明。 | 示例不改变真实任务、成果、额度或外部回执。没有明确服务回包时不造链接；来源/范围变化撤回使用许可，个人历史文档与当前交付分开，团队不打开失效结果。 |
| 4. 人物的实际交流内容线索 | 记忆 → 人物列表及人物详情，补充来自实际发言的内容标签、交流线索及对应原话入口，便于接着上次的话题。 | 仅使用明确 personId 绑定且已核对姓名的当前可见发言。标签是原话内容关键词，不是推断的个人兴趣；匿名片段、同名人物、私密和共享范围继续分别处理。 |
| 5. 可纠正的“Oops 对我的理解” | 记忆 → 记忆 → Oops 对我的理解 → 核对。分别展示本人填写的身份、本人设置的助理偏好，以及来源有效的已确认目标和背景；提供适用场景、更新信息、来源及纠正入口。偏好页可补适用场景。 | 不展示理解度百分比，不自动推断人格、决策偏差或关系亲疏。身份/偏好有真实记录时间才展示精确更新时间；历史缺失时间标明未记录，不补造时间。 |
| 6. 跨页紧凑录音条 | 当前活动会话的现场使用完整控制；其他页面默认紧凑，可展开/收起。紧凑态直接提供暂停/继续与结束，展开后可标记重点、返回现场及查看标记。内容、任务固定操作及提示同步调整占位。 | 切换会话、空间、页面或分栏清除旧展开状态；键盘打开时隐藏。继续使用原结束快照、保存范围核对与取消恢复，没有改动硬件唤起或保存规则。 |
| 7. 首页官方形象状态动效 | 首页沿用官方形象，根据可见的活动记录、本人助手工作和待核对信息呈现待机、聆听、准备、待核对或准备中断的轻微姿态及状态文字。 | 状态来自当前前端对象，不假装得到新模型/硬件能力。暂停时停止相应姿态动画；遵守系统减弱动态设置。没有重新绘制表情、冒充真实眨眼素材或持续抢占内容注意力。 |

实现位置：`src/features/DocumentRoleDraft.tsx`、`src/documentRoleLogic.ts`；`src/features/Tasks.tsx`、`src/assistantWorkPresentation.ts`；`src/features/MemorySettings.tsx`、`src/memoryPeoplePresentation.ts`；`src/features/RecordingControls.tsx`、`src/prototype.css`；`src/features/Home.tsx` 及各自样式。

## 真实后端与当前原型的衔接

现有安卓与服务器已具有音频/转写处理、五分钟环形缓冲、会话存档上传、会议/任务/项目读取和核对、已保存 AI 纪要读取及飞书机器人工作助手能力。本轮优先保留这些接口和流程，不另造后端模型替换它们。

公开 React 原型中的工作助手状态与真实安卓 H5 模拟预览仍是隔离示例。App 的工作提交、在线状态读取和结果取回接口尚未接通；说明页必须继续区分“已有机器人能力”和“App 已可真实调用”。新成果承接结构只接受明确绑定的服务结果，不凭任务 ID 拼造文档或文件地址。对外发送、共享、建日程与业务完成继续独立核对。

文档角色流程仍是示例选择或本人粘贴正文后**手动选段**，再生成可编辑的本地字段草稿。真实飞书授权、文档列表/正文读取及模型分析另属接入工作；本轮没有上传或分析真实公司文档。应用当前档案不自动替换已经确认的历史角色记忆。

真实接入工作助手前还须落实一个取消边界：当前本地演示允许在 `queued`/`preparing` 中切换类型并重置示例，因为没有真实请求。接入 worker 后必须先取消旧 job，或锁定类型直到旧请求结束；不能把本地 `reset` 当作服务器已取消，也不能因此发出重复工作。已有请求编号、防重、冻结范围和回执语义应继续沿用。
