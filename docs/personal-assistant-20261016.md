# 个性化个人助理（2026-10-16）

设置新增「个性化助理」，记忆中的「Oops 对我的理解」可进入同一管理页；保留现有导航和身份/偏好编辑入口。本人确认的身份、偏好、背景、目标与习惯按通用、会议、汇报、写作、研究使用，可以修改、停用或删除。

习惯学习默认关闭。开启后只从已核对为本人的明确表达产生候选；确认前不影响建议。所有状态按表达及原句跨场景去重，拒绝不重复提出。确认后才保存必要独立短依据，每段≤140字、合计≤280字；超限显示原因并提供手动记录入口。日常停止后已确认短依据独立保留，来源主动修订、删除或身份撤回仍会失效。

私人问答与个人草稿显示本次使用的背景，可临时排除。实际快照与界面场景、范围一致；达到条数或长度上限后补入的背景也会显示。偏好影响回答组织、材料排序和草稿结构，生成固定本次上下文，完成时只核验。修改来源、偏好、开关或范围后撤回旧准备；团队任务不带私人上下文，旧团队scope不能被准备页覆盖成个人范围。

## 真实同步与边界

- React网页继续本地隔离示例，不连接真实账号、会议或模型。`?board-preview=personal-assistant`提供编写的偏好沟通示例，不覆盖自由体验数据。
- Android设置和记忆新增「个人助理与记忆」，通过既有原生个人会话读写档案、偏好和已确认记忆。凭据不进入网页。未绑定时可直接进入「我的飞书」。
- 同一已验证账号的多设备读取同一记录，界面提供显式刷新。冲突保留本稿、对照新版后再保存；结果未知沿用原操作号和正文。换号、服务切换或解绑清旧正文并拒绝迟到回包。不自动迁移旧浏览器示例或未知归属数据。
- 本改动以PR #14的 `codex/backend-personal-reliability@216e63c` 为个人身份依赖，不重复复制账号基础。
- 实际研究、报告、PPT的新任务提交仍未接通。本轮提供可信服务端上下文快照及再次验证方法，供后续提交链路使用；不能把本地草稿或快照接口当作真实Agent已执行。

## 接口

沿用服务访问凭据，并要求 `X-Oops-User-Token` 对应当前已绑定本人会话。显示名、客户端account和共享服务token不代替本人身份。

| 接口 | 用途 |
| --- | --- |
| `GET /v1/personal/context` | 读取档案、偏好、记忆和版本 |
| `POST /v1/personal/context/profile` | 确认保存档案 |
| `POST /v1/personal/context/preferences` | 确认保存偏好、场景及开关 |
| `POST /v1/personal/context/memories` | 确认保存记忆 |
| `POST /v1/personal/context/memories/delete` | 删除并保留递增版本标记 |
| `POST /v1/personal/context/snapshot` | 构建指定场景和所选记忆的快照 |

写入带 `op_id`、`expected_revision`；保存另带 `confirmed:true`、`value`，记忆带 `memory_id` 和manual/meeting来源。字段、长度和条数有界；同操作同正文幂等，换正文或旧版本返回409。所有记录保留scenarios，偏好另有context。

存储按服务器验证的tenant/open_id稳定账号隔离；SQLite事务保护版本与回执，最终提交在账号本地锁内复验绑定。账号忙返回 `PERSONAL_CONTEXT_IDENTITY_BUSY`，保留同一操作重试。原生白名单请求字段并核验身份、对象及操作版本。

会议来源绑定持久服务UUID、原话ID及单调版本。修改、删除及既有后台期限扫描会清除派生正文；某设备暂时没有来源读取权限只隐藏，不误删其他设备有效记录。快照最多20条记忆、12,000字符，按场景和选择过滤。执行端须保存服务端快照，并在使用前调用 `validate_snapshot` 重建校验；不信客户端正文或自算hash。快照不扩大执行、发送和共享权限。
