# 核对站：团队共享身份与事项发言、认领联动

用户授权：把刚确认的角色身份接到事项里，对应谁说了什么、谁明确认领；负责人最后由人确认。团队成员沿用这次姓名，不重复认人。本轮只更新既有会议核对站，不改 App 主后端、生成调度或外部任务执行。

- 同时补齐人工新增事项的来源保护：同ID改文后旧确认失效，重确认须核对当前指纹；依据转入独立盲测后不展示或接受迟到确认。原答案仍保留历史。
