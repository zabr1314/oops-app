# 私有标注工作台：AI 预分类与人工核对

用户要求将原私有标注链接改为 AI 先分类，人工主要核对和纠错；普通事实独立分类，连续表达合理分段，保留少量独立盲测。现有声音组工作区、原始单句、各人的答案及来源指纹继续保留。

## 行为

- 内容类别为事实、观点/方案、任务、决定、无关内容。模型还能返回“不确定”，必须人工选择；事实仅表示原话作了事实陈述，并不证明真伪。
- 使用现有 DeepSeek 服务的 `deepseek-flash`，按上下文分类并分段；不改原文、原子句 ID、时间，不推断身份或负责人，不执行转写里的指令。跨说话线索、长停顿、过长表达及盲测位置是不可跨越的边界；对边界内连续句可合并，对混合类别可拆分。
- 建议单独存为每场 `suggestions.json`，生成、GET 和播放均不会提交人工答案。界面展示建议类别、理由及模型；确认后保存辅助核对来源，可修改和撤销。
- 本页批量确认仅作用于当前筛选中实际列出的有限范围，先展示具体原话；任务、决定、不确定、旧答案及逐句例外不参与。任务确认类别后仍需人工选择负责人，未选不计为内容完成。
- 旧人工答案兼容旧分段来源指纹；新分段不抹除已有答案。单句例外优先。辅助核对、盲测和身份操作分别撤销，重读恢复和幂等回执沿用原流程。
- 来源、提示版本、建议内容与指纹均核验。来源变化停止展示和确认旧建议，历史答案仍留在原文件中供重新核对。旧无来源接口无法伪造独立盲测。

## 盲测和评估

调用前按原 ASR 父段固定约 5% 样本，初次抽样排除已有人工内容答案的父段。此次三场共 324 个父段、1628 个原子句，保留 18 个父段、81 句：0235 为 9/32，0236 为 4/35，0238 为 5/14（父段/句）。固定样本不会随答案或模型结果重新抽取。

盲测句不在模型目标或上下文中，辅助页面不返回盲测句；盲测页面不显示建议和全场搜索。服务端记录已提供建议的句子，撤销不能抹去 AI 暴露。内容答案按辅助、明确盲测、历史未知来源分开计数；内容覆盖、声音组身份覆盖和独立说话人证据继续分开。

合并导出使用当前语义表达且兼容旧来源，保留每句核对方式，混合人工数据只用于开发评估。独立盲测评估仅收录同一原 ASR 父段全部子句均有有效独立答案的父段；短句不能自动视为已核对。上述抽样不是独立真实会议留出集，不证明模型、声纹或自动负责人达到验收条件。

## 调用预算与部署

收费调用只通过显式 CLI 执行，浏览器不调用模型。初次报价冻结模型、源指纹、盲测、批次、输出上限、次数和预算；跨进程锁防止重复执行，调用前持久化占用预算。失败不自动追加收费重试。重试须单独报价批准，仅可作用于失败批，保留原成功结果和调用历史，同一批准重复执行不重复收费。

三场初次报价上界 ¥4.491590，用户批准本轮最高 ¥4.50；按[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)的高峰缓存未命中输入 ¥2/百万 tokens、输出 ¥8/百万 tokens 保守估算。首轮 99 批中 95 批通过，4 批因分段越界被拒绝；按回包 tokens 核算 ¥0.584790。额外一次重试报价仅覆盖这 4 批，上界 ¥0.180888，用户单独批准 ¥0.19 且仍在总上限内；执行前确认累计保守用量加全部重试上界 ¥0.765678 < ¥4.50。

四批各重试一次均成功，无自动额外重试。最终累计 103 次调用，prompt 169214 tokens、completion 33669 tokens，按上述价格核算 ¥0.607780，所有调用均有 usage 回包。三场分别完成 508、256、330 个建议表达，共 1094 个，覆盖全部 1547 句非盲测原话。所有 18 父段/81 句盲测保持原计划。实际账单可能因缓存或时段更低；这里不把按回包估算当成账单核销。

部署仅替换私有工作台代码并增加建议文件，不上传本地复制的答案覆盖线上答案，不改音频、原话、身份、共享范围或密钥。发布前保存可回滚的代码及私有 JSON/config 快照，核验服务器原代码和真实来源；发布后验证原公开入口的鉴权 API、两种核对模式、建议覆盖和盲测隔离，并检查旧私有文件哈希。真实会议、音频、建议、凭据、费用原始回包均留在忽略的本地 build/私有服务器中，不入 GitHub 或公开体验站。

本机与服务器 Python 相关回归均 126 项通过，覆盖费用预占/重试幂等/进程锁、分段严格验证与安全拆分、盲测隔离、事实、旧标签兼容、逐句例外、批量原子性、不同方式撤销及连续撤销不复活旧答案、来源变化、合并导出和评估。测试仅使用临时数据及合成模型，不是分类精度验收。移动运行时 28 个保护文件检查通过。内置浏览器使用合成会议实测确认、修改、撤销、任务负责人、范围确认和盲测切换，未给真实会议代填答案。
