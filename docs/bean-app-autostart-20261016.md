# App 开始后直接启动录音豆（2026-10-16）

用户授权实现 App 点击开始后调用 SDK resumeRecord，并做不按硬件录音键的真机尝试。只改 Android 主版的现有录音链路；没有部署后端或公开网页。

## 行为

- 开始入口仍需本人确认本场正式会议云保存，沿用原音/全文独立保留期。SDK 日常模式限制、声纹授权和其他音源保持既有规则。
- SDK 鉴权、扫描、连接后读取 recording。已在录音则获取实时音频；未录音则每条连接仅调用一次公开 resumeRecord。设备信息与鉴权重复回调不重复启动。
- RECORDING 状态触发实时传输，解码后的完整 PCM 帧才确认 sourceReady。Opus 包到达或方法返回本身不当作出音成功。
- 鉴权20秒、扫描32秒、连接35秒、设备状态12秒、初始出音15秒设截止时间；SDK 可先返回自己的失败。失败显示具体原因并关闭该次连接，发过启动指令的路径尝试暂停后再断开，不重发未知启动、不静默改用手机麦克风。
- 原有同场暂停/继续、结束和临时副本租约继续使用；启动不改变本场会议ID或保存合同。结束/暂停后不因重复设备信息自动重新开始。

## 主版安装

使用原包名 com.oops.app 和原签名覆盖安装，没有卸载或清数据。原包的 H5 与当前改动前源码完全一致；新包没有缺失 assets/res，唯一变化的 bundled asset 是 app.js。构建配置与原包逐字段相同（只输出比较结果，不输出凭据）。484个 App DEX 类总数保持一致，发生名称替换的两个类均是本次 SoundcoreBeanLink 内的匿名回调；既有业务实现保留。

覆盖前已备份153份非原音业务文件与原APK。第一次覆盖后0份缺失，除系统 files/profileInstalled 标记外152份校验值一致；新增文件为运行过程数据。最终安装包已从手机回读并与准备包哈希核对一致。凭据、备份、安装包及明细只在忽略的 build/bean-autostart-20261016、既有 bean-main 私有目录，不提交到Git。
