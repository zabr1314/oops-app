# App 本机缓存优先

用户要求已经读过的内容尽量放在 App，减少重复下载；新内容和变化内容再向服务器取回。

## 本轮实现

- Android 原生 HTTP 读取增加私有显示缓存，覆盖会议列表、详情、已有纪要、项目列表/详情、正式任务列表及会议候选。个人档案本来就在本机，本轮不复制或上传它们。
- 页面请求可以先收到有效本机快照，再收到同请求编号的服务器核对结果。缓存首包不结束请求，不把旧纪要恢复提示成新结果，也不触发模型、任务发送或业务完成。
- 后端对白名单 GET 的最终 JSON 计算 ETag。先走原鉴权、来源和到期读取，再比较版本；未变化返回 304，无须重复传输正文。服务器仍执行来源核对与结果计算，本轮没有实现逐条增量同步或轻量变更索引。
- 已有正文在后台更新时继续显示；切后台/离线只停止读取。临时错误在有效展示期限内保留只读内容并显示尚未更新，避免切页和短暂失败闪空。
- 当前可见详情、纪要、项目和任务在展示租期结束前后台核对；会议列表沿用前台约20秒的原同步调度。没有内容变化时依赖条件 GET 复用本机正文。

## 期限与来源保护

缓存属于显示快照，不能作为个人身份、核对许可、派工许可或业务完成回执。核对详情、Raft 授权合同、发出确认与原声下载不进入该缓存白名单。

文件位于 Android `noBackupFilesDir/browse-cache-v1`，键使用服务器地址、服务凭据范围、个人会话、已核绑定版本及请求路径的哈希；不把凭据原文写到缓存索引。普通浏览启动时只读核对一次个人绑定，无需先打开飞书设置；旧服务不支持个人会话/状态时保留原读取方式，不启用该缓存。

有效显示租期最多60秒，且不能超过原全文来源到期。来源合同明确且完整的响应最多保留24小时供后续条件核对，仍不得超过任何关联来源期限；来源合同未知的旧结果仅短时保留在内存。混合来源必须全部具备有效合同才可落盘。容量最多96项、约32 MB；大于8 MB的单项不缓存。

缓存失效、服务/身份变化与响应写盘使用同一同步锁，网络正文读取在锁外，避免慢网络阻塞服务切换。写入修改后撤销相关旧缓存；删除、权限或来源失效时收起关联显示，迟到响应不能重建已撤销快照。同路径的项目/任务并发读取保留新请求结果，防止旧回包覆盖。

本机到期后不再展示或复用正文，访问时清理过期文件；App 未运行时不承诺精确时点的物理擦除。缓存恢复不改变原保存期限、默认短会/零句过滤、人工答案或已发送任务的真实状态。
