# 真实会议与多只 Oops 协作回放

独立入口为 `public/funnel.html`，体验中心沿用原入口。公开站只提供编写示例；真实会议继续存于后端既有 `meetings/*.json`、`feishu/state.json`，由独立只读网关投影，不复制到公开资源中。

## 数据与动画

- 现场区区分原会议历史、当前规则重算和独立 Jev 重新分析；已保存的问题、输入、模型、选项概率及耗时可逐步展开。未记录的数据保持缺失，成功纪要份数不冒充实际调用次数。
- 会后区读取已有纪要事项和原话依据，按纪要、资料、人工核对、飞书工位展示交接。问题摘要不证明查询成功，规则通过不证明人工确认，建文档不证明发送成功；历史回执与本次分析分开。
- 页面是三栏：左为原话（会后为事项），中为 Jev 的蛛网和 Oops 接力，右为判断／事项详情。窄屏改为单栏，详情从底部抽屉打开。
- 会中蛛网：每条线是当前这句已经回放到的一个已存问题，颜色表示规则／Jev／生成／你，长度表示已存概率；没有概率的画成虚线，不补算。每处理完一句，网向外多一圈。小蜘蛛只在刚回放到的那条线上停留，暂停或减弱动态时回到中心。
- 会后蛛网：中心是纪要，节点是沿用纪要的事项；原话依据、规则复核颜色和待核对序号按引擎阶段依次出现。点节点打开对应事项。
- 参考原录屏的爬虫效果：Jev 作为线框爬虫在整页行走（`funnel-crawler.js`），依次走到刚回放到的原话、对应蛛网线和判断卡，落脚处高亮并弹出已存答案；会后依次走到事项和工位。只标已存结果，减弱动态时不显示。
- 下方接力带用官方 Oops 形象表示聆听、判断、查询、纪要、飞书（会后为纪要、资料、核对、飞书）；没有执行记录的工位置灰，只有判断工位在已存判断回放时活动。
- 控制默认保留播放、进度、切换会议和更多，细节按需打开。暂停、隐藏页面、切模式、换源或减弱动态立即停止；来源失效清空所有可见内容。

2026-10-15 起不再使用原参考录屏的家具、墙屏和金融数码裁图，也不再使用八格仪表；这些素材与 Oops 无关，已从仓库和部署清单移除。

## 私有读取与失效

网关使用绑定明确会议、用途和有效期的一次性邀请，换取路径限定的 HttpOnly 会话。授权数据库与源会议分开，只保存邀请／会话哈希。服务限制回环网络，源目录只读；公开站不包含服务全权限凭据、真实转写或重新分析正文。

原话、身份、来源版本或全文期限变化后，旧轨迹和重新分析不可读取；清理定时器移除派生正文，仅保留数字费用回执。未来实际发生的分类可由 `ProcessingTrace` 旁录，未归档数据最多在内存保留五分钟，只有相同来源版本才能附入既有会议；不补算旧历史。

列表和正文请求各自使用版本号。列表失败保留 401、503 或网络原因，只有成功读取授权列表才判断指定 run 缺失。刷新恢复用户明确选择的 run；用户另选会议、示例、文件或退出优先，迟到列表和正文均不能覆盖。只读 GET 遇网络、429、502、503、504 最多重读两次（500ms、1000ms）；POST、DELETE 不重试。

## 收费边界

38句会议曾在用户批准的 ¥0.10 上限内完成一次独立 Jev 重新分析；本次回放只使用已存结果。运行器逐请求持久预算预占，未知结果保留最坏占款并停止，不自动重提；既存任务拒绝重复执行。概率是模型本次的选项分数，不是实测准确率或内部思维过程。原会议与纪要不改写。

`scripts/jev_reanalysis.py` 是收费执行工具，不能作为回放或测试命令运行。单元测试使用内存假传输。历史网关、前端播放、事项投影和重读均不调用模型、ASR、资料查询或飞书。

## 验证与发布

前端测试通过 `npm run test:funnel` 运行，包括实际脚本的 VM 播放、选择、迟到响应、加载失败恢复、权限失效、暂停和会后来源语义。`test:logic` 也包含全部五个文件；Sites 打包检查覆盖回放脚本与样式。

从最新 `main` 的独立工作区验证：60项回放 JS、74项转换／网关／预算／轨迹 Python、5项升级工具 Python、46项既有质量／读取／保存策略 Python、28个受保护运行时文件、生产构建和4项 Sites 检查全部通过。构建仍提示既有主 App bundle 大于500 kB；Python既有测试出现资源未关闭警告，均未导致失败。
