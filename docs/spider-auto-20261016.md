# 新录音自动接入蜘蛛页（2026-10-16）

用户明确要求后续新录音自动接入原蜘蛛页，不再逐场手动添加，并直接查看实时处理。本轮取代 `spider-live-20261016.md` 中“未来会议不自动开放”的范围限制；其他来源、保存、只读及撤回规则继续保留。

## 自动范围与读取

原历史页仍为用户此前要求的免邀请只读入口。`open-access.json` 保留两个固定会议，新增：

```json
{
  "auto_meetings": {
    "enabled": true,
    "from_started_at": "2026-10-16T04:15:10+00:00",
    "excluded_meetings": []
  }
}
```

每次请求直接核对 owning store，不把新 ID 或正文复制进访问库。自动范围为北京时间今天12:15:10之后开始的正式云保存会议：version 1 合同、明确云保存、开始时间一致、转写保留期有效。起点原误用快57分39秒的服务器时钟记为13:12:49，后续稳定性排查已校正；区间内没有已存会议，未新增开放既有内容。排除日常临时内容、旧无合同记录、启用前其他历史、已删除/到期及单独预制回放。单场动态排除、关闭开关或删除配置在下一次读取生效；原独立个人邀请仍按其明确授权读取。自动排除不撤销同一 ID 的固定或个人明确授权，撤回时应同时移除对应独立许可。

`GET /api/meetings` 返回 `auto_connect.enabled/from_started_at`。即使当前没有录音，开启的自动模式也允许返回 200 空列表，持续等待首次同步。查看页面不启动录音，不重跑模型/ASR/查询/飞书操作；新录音仍通过手机既有正式会议同步到服务器，页面显示已保存的处理结果。

## 页面行为

- 固定入口 `https://giftedprofessor.xyz/oops-meeting/history/?auto=1#live`；不带指定会议/分析的根入口也默认自动跟随。
- 每5秒刷新授权列表，发现最新正式会议后自动载入并跟随新原话和已有处理轨迹。页面关闭期间的新会议也会在下次打开时发现，不需要新增 ID。
- 可“暂停自动切换”；手选历史、查看旧句、播放历史、示例或本机文件会暂停自动切换。新会议仍加入列表，保持用户查看位置，点“自动跟随新录音”恢复。
- 显式 meeting/run 深链接默认保留指定对象；自动入口不绑定旧 ID。迟到发现/正文请求受导航版本与自动模式代数保护，暂停、换源、退出后不抢跳。
- 超时或读取失败清空无法核对的服务器正文，自动模式可从新授权列表重连；后台列表失败不清空独立示例/本机文件。撤权、删除和到期在正文条件请求之前重新校验。隐藏页面停止读取。
- 自动扫描与已打开正文沿用压缩、ETag 和 no-store。页面核对间隔为5秒，麦克风到显示的总延迟还受手机 ASR、分类和同步频率影响。
