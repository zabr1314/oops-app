# 手机个人飞书连接与任务核对（2026-10-16）

本次提交只包含个人飞书连接、纪要交付、任务读取与核对的代码。工作区中的录音豆控制、日常聆听结果、Sol 模型、纪要自动同步、Raft、Apple Watch 和 PR #10 设计改版不纳入本提交。已安装的综合 APK 仍保留这些既有能力；本次拆分提交没有重新构建或重装手机。

## 手机链路

- 原生 HTTP 客户端保存按后端地址隔离的个人会话；使用 Android Keystore 加密，不向 H5 暴露凭据，不回退到共享飞书身份。
- 设置中提供“我的飞书”，接官方授权页面与 `oops://feishu/complete` 返回。任务归属以绑定的个人飞书身份核对，本机显示名不能切换账号或授予权限。
- 纪要发送先读取并核对来源、正文、收件人和文档权限，再以当前草稿版本明确确认；未知结果只查同一操作，不自动创建新发送操作。账号绑定或来源变化会撤回旧确认。
- 已人工核对的会后事项可复用服务端来源回执整理飞书任务草稿；历史会议与当前录音的会话、依据、负责人及业务完成分别处理。
- 正式任务与会议候选独立加载、失败和重试，候选的原话与个人核对面板在 App 内打开，详见 `task-review-in-app-20261016.md`。

飞书开放平台上的范围发布属于配置操作，没有应用密钥或用户令牌进入本提交。新手机已经以洪玉麟绑定并读到16条真实候选，真实核对面板已打开；代理没有提交真实人工答案，也没有借此发送消息或创建任务。

## 后端依赖与部署差异

香港生产已有个人 OAuth、账号存储、纪要交付及批量核对读取模块；它与当前主分支源码并不完全相同。本提交的手机适配使用这些已有接口，不把生产整份后端覆盖回主分支。新的核对接口只有在个人会话模块已接入时才可使用；缺少模块或身份时明确拒绝，不授予共享身份。

`deploy/task-review-production.patch` 保存针对当时实际生产 `local_backend.py` 的最小差异，包含列表身份只读快照、候选拆分、核对路由与能力标志。`deploy/task-review-manifest.json` 固定部署前后源码 SHA256。需要复现该历史补丁时，以匹配 `before` 的源码建立独立 stage，应用补丁、复制 `scripts/app_task_reviews.py` 和 manifest，再交给 `deploy/task-review-upgrade.py`；升级工具在写入前核对哈希，备份、健康回读失败时回滚，并保护现有批量 adapter。当前生产已经更新，不能直接再次应用旧 `before` 清单。

生产备份、构建、原签名覆盖安装、ASR收尾及数据一致性的实际记录见任务核对文档。本次提交仅做必要语法、差异与运行时完整性静态核对，未运行测试套件或新构建；先前获准的一次综合 APK 构建不等于这个拆分提交单独通过构建。
