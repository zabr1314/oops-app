## 跨模块验收规则

1. **更正说话人**：仅指定片段或明确选择的同匿名标签范围改变身份。相关任务撤回助手许可、记忆转待核对、旧理解/决定不能继续采用。任务负责人保留原分工，复核时显式核对提出人；不能把“谁说话”自动等同“谁负责”。
2. **编辑/删除原话**：依精确片段及引用链失效。旧成果保留待复核，旧答复不能继续派生，共享及团队导出拒绝失效资料。无关任务不改变。
3. **人物改名/同名人物**：当前工作使用稳定人物 ID；历史原话、已发送回执保留原快照。未绑定 ID 的旧姓名不进行猜测式批量迁移。
4. **项目改名/背景变化**：精确项目标签随名称迁移，工作空间保持。项目或记忆的派生结果撤权待核对，个人汇总仍保留查找路径，团队视图过滤未核对内容。
5. **要求/期限变化**：未结束任务撤回旧准备许可；迟到生成回调不能写入或扣额度。内容变化重开时归档完成结果；已完成工作仅改日期不重开。
6. **记忆核对/弃用**：最新引用逐条可查看，失效引用先处理，二次变化重新核对；弃用递归撤回派生许可。恢复内容不自动恢复共享和助手许可。
7. **沟通/日程**：正文、对象、附件版本、账号、范围与提交快照一致；修改后重审，重复确认返回同一回执；日程冲突在确认时再检查。
8. **本次试用与自由体验**：画板、引导试用使用隔离示例，不读写用户持久化内容；刷新示例重新开始。原有用户数据不重置。
