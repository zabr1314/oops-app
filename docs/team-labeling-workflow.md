# 团队标注：音色批量确认与连续表达

本次只更新既有私有标注站，原来的完整链接继续使用。没有替成员提交真实答案，没有重新聚类、调用收费模型或启用归属门禁。

## 操作方式

1. 选择本人身份。音色组展示代表录音、成员数量、会议范围和全部原话；已有声纹/代认领仍是建议。听录音后选人，点击“确认关联 N 句”。
2. 身份批准属于当前标注者，单独保存在 `identities/<姓名>.json`，绑定组成员和内容指纹；不把组成员批量写成逐句听过的真值。单句修正或“移出关联”优先，撤销组确认不会删除这些例外。
3. 连续表达合起来显示和播放。只在同一原 ASR final 内、时间相邻且声音提示一致时合并，间隔不超过1秒，总长不超过25秒/160字。声音变化、重叠和缺少父段信息会断开；这些边界是核对辅助，不是已验证的说话人切点。
4. 点击整段内容按钮明确覆盖原子句，包括本段短上下文。任务需另选负责人，重复任务/决定可选同组字母。内容不同或身份混入时展开逐句纠错；后续整段操作保留已有单句例外。
5. “撤销本场上一步标注”恢复本场内容或单句操作；“撤销上一步音色组操作”恢复组批准。两类历史各保留最近30步，刷新后仍可用。清空单句内容使该句待核对；如需恢复之前值使用撤销。

每次写入等服务器回执才显示已保存。版本冲突要求重新核对；网络失败保留待提交操作并使用相同请求ID重试，不重复执行。旧页面无版本号的全量保存返回409，避免迟到保存覆盖新纠错，升级后需刷新原链接。

## 数据与验收

原始句ID、文本、时间、父段与音频保持原样。内容批量操作记录 `kind_source.mode=expression` 与表达指纹；单句核对记录 `mode=single` 与原句指纹。旧无指纹标签保留兼容并明确限制，来源变化的新标签会撤回就绪资格，不能默默降级成旧式答案。

原页面的长句数量合计1076；新表达数量与原始 ASR final 数量（324）不同。短上下文不是自动无效：若本身构成任务/决定，仍可展开标。一旦开始标注的短表达缺负责人或出现分歧，也会进入待核对。

`label_readiness.py` 分开报告：

- `ready_for_content`：必核对表达及已开始的短表达，其类别/任务负责人都完成且无分歧。它不依赖说话人姓名。
- `ready_for_cached_content_evaluation`：至少有一个原 ASR final 的全部子句内容完整。
- `independent_speaker_rows` / `grouped_speaker_rows`：直接逐句身份核对与批量组关联分别计数。
- `ready_for_calibration`：全量内容准备条件，仍不代表已拟合参数；`calibration_complete` 和 `real_meeting_accepted` 保持 false。

`evaluate_cached_labels.py` 严格核对所有父段ID和原文，只评分全部子句内容完整、无类别/负责人分歧且来源当前有效的父段；其他父段明确排除并报告原因、句/段覆盖率。身份缺失或分歧不阻止内容指标，声音组关联不代替内容标签或独立说话人真值。没有完整父段时不输出指标。短上下文未标造成对应父段不完整时，该父段仍不评分，不能把它补成无效来提高覆盖率。

这些三场记录已经反复回放，仅用于开发诊断；批量标签之间有关联，不是独立样本。校准及未见真实会议验收仍需冻结配置和独立证据。

## 工作台界面优化

原有同音色/连续表达能力保持不变，页面改为两个工作区：

- **标内容**：默认待核对；列表可搜索原话、查看全部或任务/决定，当前一段集中展示原话、原声和四种类别。单句先显示身份及内容结果，点“修改”才展开身份、类别和必要的负责人/重复项。单句例外继续优先。
- **认声音**：音色组有独立列表和代表录音，选择身份后显式确认关联范围；范围列表可搜索并跳到对应会议的单句编辑，顶部会议选择同步更新。

保存状态常驻顶部；撤销随当前工作区显示，内容/单句与音色组仍是独立历史。自动下一条为可选偏好，只在收到保存回执且本段内容完整后推进。连续播放只沿当前列表；原声使用真实浏览器音频控件，切换表达/音色会停止旧音频，编辑同段不会反复重建播放器。

空搜索可恢复；超时保留同请求重试。409 或身份保存后刷新失败不会继续允许按旧界面编辑，也不会把未应用的操作报成已保存。必须完整重读成功再恢复。页面模板单独存于 `scripts/team_label_ui.html`，部署时须与入口脚本一起安装。
