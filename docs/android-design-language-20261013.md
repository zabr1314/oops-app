# Android H5 按「Oops 设计语言」改版（2026-10-13）

用户要求按根据品牌 logo 做的「Oops 设计语言」重新设计安卓 App 的界面、交互和动效，并明确改的是安卓端（`android/app/src/main/assets/web/` 里的 H5 及原生外壳资源）。设计语言的权威来源是设计系统 [Oops 设计语言](https://claude.ai/artifact/3CTw3hmM1WXNBxmALvaLxh)（令牌、组件、吉祥物、动效、文案）。本次只改外观、交互和动效，不改业务规则、桥接协议、接口或保存策略。

## 改了什么

**视觉层** `oops-design.css`（在 `proto.css`、`app.css` 之后加载，只覆盖样式，不改行为）
- 令牌：画布 `#f2efff`、主色 `#6449ea`、正文 `#121130`、次要文字 `#4b4869` / `#686589`、圆角 6/10/16/24/32、阴影与缓动曲线；拉丁字符用 Nunito（OFL，`fonts/` 内附许可），中文沿用系统字体。
- 每屏只有一个渐变重点（主按钮），开关、芯片改为纯色；红色只表示「正在录音」（录音点、结束）。
- 图标改为按文字颜色着色的蒙版（`icon()` 输出 `<span class="icon">`），选中、禁用、危险状态自动跟随颜色。
- 卡片、列表、徽标、芯片、分段控件、表单、底部面板、Toast、提醒横幅统一按组件规范；底部导航改为悬浮胶囊；说话人头像按人固定颜色（本人固定主色，「说话人 B」显示 B）。
- 已逐页做对比度检查：14 个页面/状态里所有可见文字均达到 WCAG AA（正文 ≥ 4.5，大字 ≥ 3）。

**噗噗（吉祥物）** `pupu.js`
- 形状按官方 `brand/mascot.png` 描出：右上偏的圆角三角，不是圆形或椭圆（用户 2026-10-13 明确纠正）。眼睛、三道惊叹线位置同官方图。
- 只在情绪时刻出现、每屏最多一只：空状态睡着（sleepy），没找到（oops），等待/读取（thinking，350ms 后才淡入，快速读取不闪现），完成（happy / cheer），录音中聆听（listening）。
- 动效只反映可见的真实状态：首页英雄区在收音时换成聆听姿态，声波亮度跟随原生上报的真实输入电平（`state.level`，每 0.5 秒）；等待音源时静止；未录音时显示官方原图并轻微浮动。不以动效暗示模型或设备在工作。

**交互与动效**（`app.js`）
- 页面切换上浮淡入，新主导航项弹一下；分栏切换同样上浮；底部面板带弹性滑入，遮罩淡入；Toast、新提醒横幅弹入（横幅只在首次出现时动画，状态刷新不再反复闪烁）。
- 新转写句子从下方滑入一次；原文与现场概览都有。
- 所有可点元素按下有果冻回弹（按下 0.94、松开带回弹曲线）。
- 录音控制：现场页（会话 · 现场）保持完整控制；其他页面默认收成一行胶囊，「找回刚才」和「结束」一点即达，可展开查看「已保存」；展开状态只属于当前页面和分栏，换页或换分栏不继承。与 React 版已定稿的「现场完整、其他页紧凑可展开、结束可达」一致。
- 首页记录中：标题改为「日常临时聆听 / 正式会议」，开始时间放到上方小字；状态行加输入电平条（同样来自原生真实电平）。
- 系统「减弱动态效果」打开时，所有动画在 1ms 内结束，噗噗与录音点不再闪动（已用浏览器检查无持续动画）。

**顺带修复**
- 打开过现场「原文」后再换页，`mountTranscript` 报 `appendChild` 空节点错误，导致导航高亮、录音控制等后续渲染中断（改前同一截图流程出现 8 次报错）。改为持有转写节点引用；改后同一流程 0 报错。

**原生资源**（未在本机构建，见下）
- 启动图标：自适应图标，前景为官方噗噗原图（适配 66dp 安全圆，5 种密度），背景为淡紫渐变；Android 13 主题图标使用噗噗剪影（眼睛镂空 + 三道线）。清单改用 `@mipmap/ic_launcher`，删除旧的占位图标。
- 通知栏小图标：录音时显示「聆听中的噗噗」剪影（两侧声波）；通知强调色改为品牌主色。
- 主题色 `oops_brand` / `oops_bg` 与 H5 一致；WebView 首帧背景设为画布色，启动不再闪白。
